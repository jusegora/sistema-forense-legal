# Sistema Forense Legal

**Por:** jusegora | Abogado & AI Solutions Architect

Herramientas desarrolladas para el análisis de evidencia digital, enfocadas en mantener la validez legal y la cadena de custodia.

## El Problema
Herramientas como Magnet AXIOM son excelentes para encontrar datos, pero el paso final (convertir esos datos en un informe que un juez pueda admitir) sigue siendo un trabajo manual y propenso a errores. Este proyecto automatiza esa brecha.

## Caracteristicas del Core
El código fuente de este sistema es privado para proteger la propiedad intelectual. Las capacidades principales incluyen:
- Aseguramiento de evidencia con hashes criptográficos (SHA-256).
- Detección de exfiltración de datos en entornos Microsoft 365.
- Extracción de entidades (nombres, montos) usando NLP local (sin enviar datos a la nube).
- Generación automática de informes periciales en PDF.
